**VELORA** — an island where the aurora touches the sea.

A night travel poster, generated procedurally by `main.py` (Python + PIL):
a deep teal-to-indigo night sky, aurora ribbons sweeping overhead, one slender
white lighthouse on a dark rocky cliff sending its beam toward the lights,
a crescent moon, distant islets, and a calm sea reflecting the aurora and the
lamp. The place name is set into the top of the scene in letterspaced ivory
serif capitals. No other copy — the name is the poster.

Run it:

```sh
python3 main.py   # writes /output/entry.png (832x1024)
```
